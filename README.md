# 银河铁道之夜 · 双人旅程

改编自宫泽贤治《银河铁道之夜》（1934，公有领域）的双人联机 3D 网页游戏。
半人马祭的夜里，乔凡尼与康帕内拉登上了开往银河的列车——邀请一位朋友，一起走完这段旅程。

**在线游玩：** https://haidongnie.github.io/ginga-railroad-duo/

## 怎么玩

1. 打开网页，输入名字，点击「启程」。
2. 点右上角「邀请同伴」，把链接发给朋友；朋友打开链接点「上车」即可加入同一班列车。
   - 第一位玩家扮演 **乔凡尼**，第二位扮演 **康帕内拉**。
   - 同伴没来时，会有 AI 康帕内拉陪你同行，可以一个人通关。
3. 很多目标需要两人一起完成：一起走到目的地、分别站上两个光环、各自向列车长出示车票……

## 技术

- **3D 资产：** 全部 22 个模型由 [Meshy](https://www.meshy.ai) API 生成——`meshy-t2.5` Smart Topology 文生 3D + PBR 贴图；6 个角色经 Meshy 自动绑骨并套用动画库（待机、行走、奔跑、挥手、拾取、坐下、交谈、鞠躬）。
- **渲染：** Three.js（WebGL2）+ UnrealBloom 辉光、ACES 色调映射；银河天穹、星空、草地、星河水面、光柱等均为自写 GLSL 着色器。
- **联机：** [Playroom Kit](https://joinplayroom.com)。房主作为权威端推进剧情状态，客户端通过 RPC 上报互动；联机服务连不上时自动进入单人模式。
- **音乐音效：** WebAudio 实时合成，无音频文件。

## 本地开发

```bash
npm install
npm run dev
```

开发服务器下可以用 `?ch=N`（0–7）直接跳到某一章。

### 重新生成 / 优化资产

资产清单在 `tools/assets.json`。生成脚本可断点续跑，已完成的任务 ID 记录在 `tools/meshy-state.json`，不会重复扣费。API Key 只从环境变量读取，不要写进仓库。

```bash
MESHY_API_KEY=你的key npm run assets:generate   # 生成到 assets-raw/（已加入 .gitignore）
npm run assets:optimize                          # meshopt + WebP 压缩到 public/models/
```

### 可选：Playroom gameId

在 [dev.joinplayroom.com](https://dev.joinplayroom.com) 注册游戏后，把 gameId 设为仓库变量 `PLAYROOM_GAME_ID`（Settings → Secrets and variables → Actions → Variables），部署时会自动带上。
